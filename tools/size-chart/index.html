使用指南

1. 界面分为三栏：左栏编辑尺码数据，中栏实时预览与导出，右栏调整主题和字体。任何改动都会立刻反映到预览上，无需切页。

2. 从 Excel 或任何表格中复制数据，直接粘贴到「粘贴导入」区域即可自动识别；在页面任意位置按 Ctrl+V 也会自动填入。

3. 「快速预设」可一键加载常见尺码数据，预设会保存完整的主题、字体和颜色设置。

4. 表格单元格可直接点击修改，悬停表头出现 × 可删列，悬停行尾出现 — 可删行。

5. 在右栏切换主题、字体搭配、表格尺寸和自定义颜色，然后在中栏顶部的工具条里设置导出尺寸，复制到剪贴板或下载高清图片。

6. 所有数据会自动保存到浏览器本地，下次打开自动恢复。
