推送记录

每次点「推送」都会在这里留一条 —— 成功、没改动、取消、失败都记， 写清时间、增量还是强制、新增几行 / 改几个格 / 清空几行、推送时本地共有多少单。 记录存在本机数据库自己的表里，只增不删：推送、拉取、整理数据都不会动它， 正常使用下一条都不会少（只有你在设置里主动「清空这个工具的数据」才会一起清掉）。

时间 方式 结果 新增 改动 清空 详情

在线表格（WPS）

每张 WPS 授权都有一条分享链接 —— 粘一条进来就认出是哪张表，之后就在本工具里 推送 / 拉取。只写台账那 14 列：你自己加的备注列、公式列一格都不动， 赔款数这类本地列的也不推（它只在工具里记）； 推送是增量的 —— 按单号比对，只写「本地新增的行」和「值变了的那些格」， 表上已有的行不重写，表上有而本地没有的行留着不动； 拉取先看差异、确认了才写库。授权在 设置 → WPS 授权 里做一次就行 （同一份令牌，不重复授权）。

还没绑定
—
推送只写新增和改动，表上多出来的行留着不动； 强制推送会把表格变成和本机一样 —— 表上有、本地没有的记录会被清空（连你自己加的备注列）。

店铺表

每个店铺一个客服 ID —— 呼起客户端时按它定位。把 ERP 给的一条链接粘进「客服 ID」那格， 会当场把 cs_… 抠出来，不用你自己去认。

下拉选项

五个下拉的选项一行一个，改完点保存。已经在单子上的旧值不受影响。 流程状态里「完结」恒定在最后一项 —— 它是收尾步，不跟着下面这格走。

跟进提醒

提醒是流程的看门狗，不用一条条去设 —— 登记一条就自动订上， 之后每记一步流程自动往后顺延，记到「完结」自动撤掉。

怎么算的
到期时刻 = 最后一次流程时刻 + N 小时；还没记流程就用登记时刻。 到点后工作台待办里会多一条带「异常单号登记」标记的待办，弹提醒卡。 改这个数只影响之后的派发，已经订着的不会回溯重算。
