直连云端表格

直连 = 直接读写你那张原表：不复制、不经过知识库、不产生副本。 第一次用要先在表格里建一个 AirScript（点「复制脚本」，步骤见下）。

第一次用？两分钟建脚本
  1. 在 WPS 里打开那张表格，点顶部「效率 → 高级开发 → AirScript 脚本编辑器」。
  2. 新建脚本，把「复制脚本」拿到的代码整段粘进去，保存。
  3. 点工具栏「脚本令牌」创建并复制令牌（需实名认证；一个账号只有一个）。
  4. 在脚本「更多」菜单里复制「脚本 webhook」，连同令牌一起填到上面。
  5. 点「直连绑定」——读出表名和表头就通了。
或者：绑定知识库里的文件（文档也能编辑）

这条路要账号登录态：先在 设置 → WPS 在线表格联动 里登录并选好知识库。 保存走「新建 → 删旧 → 改名」，旧版本进回收站 7 天。
